# 26 · Hook-Rate in 20 Sekunden

| | |
|---|---|
| **Typ / Serie** | Kurz · Hook-Bank |
| **Länge / Format** | 20 s · 9:16 |
| **Funnel** | Awareness (Education, KPI-Erklärung) |
| **Kernbotschaft** | Die Hook-Rate ist der Anteil der Zuschauer, der länger als drei Sekunden bleibt. Die eine Zahl, die man jede Woche prüfen sollte. |
| **Ziel-KPI** | Saves · Hook-Rate des Videos selbst > 50 % |
| **Blueprint** | Eine Zahl, eine Definition, ein Richtwert, eine Handlung |

Typo-Rollen: „Pill“ · KERN · **AKZENT** · *Flourish* · `Daten`

## Skript (Variante B)

| Zeit | Voiceover | On-Screen | Bild & Motion | Sound |
|---|---|---|---|---|
| 0:00 | Eine Zahl entscheidet, ob dein Video Reichweite bekommt. | **EINE ZAHL** / „entscheidet“ | Prozentanzeige `__ %` groß, Raster-Drift. | Hit |
| 0:03 | Die Hook-Rate. Der Anteil, der länger als drei Sekunden bleibt. | **HOOK-RATE** / Label `Anteil, der länger als 3 s bleibt` | Timecode-Leiste läuft bis 3 s und stoppt teal. | Ticks, Stopp-Thud |

## Ende / Loop

Prozentanzeige leert sich auf `__ %` (Frame 1).

## CTA

Save. Antwort auf Kommentare: „Wenn du deine Hook-Rate schreibst, sagen wir dir, ob der Hook oder die Taktung das Problem ist.“

## Caption

Eine Zahl entscheidet, ob dein Video Reichweite bekommt: die Hook-Rate.
Der Anteil, der länger als 3 Sekunden bleibt. Du findest sie in deinen Insights (Retention-Kurve, Wert bei Sekunde 3).
Unser Richtwert: über 40 %. Darunter wird der Hook neu gebaut. Prüf sie jede Woche.
