# 24 · Safe Zones

| | |
|---|---|
| **Typ / Serie** | Kurz · In 0,5 Sekunden |
| **Länge / Format** | 25 s · 9:16 |
| **Funnel** | Awareness (Education, Save-Content) |
| **Kernbotschaft** | Text, der unter Buttons oder der Plattform-Caption liegt, liest niemand. Oben, unten und seitlich bleibt Platz frei. |

## CTA

Save. Antwort auf Kommentare: „Gilt für Reels, TikTok und Shorts gleichermaßen, die Buttons liegen überall rechts unten.“

## Caption

Dein Text liegt unter dem Like-Button. Also liest ihn keiner.
Tabu: oben ≈ 250 px, unten ≈ 420 px, rechts die Buttons, seitlich 60 px Rand (Richtwerte bei 1080 × 1920). Alles dazwischen ist deine Bühne.
Speicher dir die Maße.
