# 14 · Mittelmaß kostet doppelt

| | |
|---|---|
| **Typ / Serie** | Mittel · Die ehrliche Rechnung |
| **Länge / Format** | 50 s · 9:16 |
| **Funnel** | Awareness → Angebot (Schmerz des Status quo) |
| **Kernbotschaft** | Ein Video, das niemand zu Ende sieht, hat trotzdem Drehzeit, Schnitt und Abstimmung gekostet. Und die Reichweite, die es nicht bekam, bekam ein anderer. |
| **Ziel-KPI** | Kommentare mit Zahl · Shares an Marketing-Kollegen |
| **Blueprint** | Bon-Drucker als Rechenmaschine, zwei Bons |

Gelbe Vollfläche kehrt zurück (Frame 1).

Kommentar mit Zahl von 0 bis 10. Antwort: „[[Zahl]] von 10. Willst du wissen, woran die anderen gescheitert sind? Schick uns zwei davon per DM.“
