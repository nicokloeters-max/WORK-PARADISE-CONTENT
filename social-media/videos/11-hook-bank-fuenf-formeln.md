# 11 · Hook-Bank: Fünf Formeln, die stoppen

| | |
|---|---|
| **Typ / Serie** | Mittel · Hook-Bank |
| **Länge / Format** | 60 s · 9:16 |
| **Funnel** | Awareness (Save-Content, Autorität) |
| **Kernbotschaft** | Fünf Hook-Formeln, die in 0,5 Sekunden stoppen: Frage, Behauptung, Visual, Zahl, Widerspruch. Je mit Beispiel. |

## Hook-Varianten (0–0,5 s)

| | Voiceover | On-Screen | Erstes Bild |
|---|---|---|---|
| **A · Frage** | „Welche fünf Hooks stoppen jeden Daumen?“ | „welche fünf“ / **STOPPEN JEDEN DAUMEN?** | Fünf Karten fallen ein |
| **B · Behauptung** | „Es gibt nur fünf Arten, einen Daumen zu stoppen.“ | „es gibt nur“ / **FÜNF ARTEN** | Daumen 3D setzt auf Phone, Feed stoppt |
| **C · Visual** | (Stopp-Thud) | `5` | Zahl schlägt ein, Karten fächern |

**Empfehlung: B.** Die Verknappung („nur fünf“) ist der Hook.

## Produktionsnotizen

- Die fünf Beispiel-Hooks sind Daumenstopp-eigene Sätze (drei davon aus dem Angebot). Keine fremden Hooks zitieren.
- Karten-Design wie das „3 Dinge“-Trio der Referenz: dunkle Karte, gelbes Linien-Icon, Label in Plex Mono.
- Dieses Video ist die Basis der „Hook-Bank“-Serie. Folgevideos nehmen je eine Formel und zeigen fünf Varianten davon.
